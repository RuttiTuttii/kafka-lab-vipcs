# как работаем с git

> у каждого сервиса свой репозиторий, этот репозиторий хранит только общее: контракты событий и локальный kafka. ветки, ревью и мерж внутри своего репо каждый ведёт сам.

## синхронизация

- контракты лежат в `contracts/events.md`, источник правды один: этот репозиторий
- изменение схемы события идёт через pull request сюда, и о нём пишем всем в чат
- `.github/workflows/ci.yml` копируем в свой репо как шаблон
- `docker-compose.yml` берём отсюда, чтобы у всех был одинаковый локальный брокер

## команды

```bash
# забираем актуальные контракты
git pull origin main

# поднимаем локальный kafka и kafka-ui на http://localhost:8080
docker compose up -d
```

## конфиг брокера

`BootstrapServers` лежит в `appsettings.json` каждого сервиса. дома `localhost:9092`, в колледже `10.9.2.80:9092`. локальные правки кладём в `appsettings.Local.json`, он в `.gitignore`.
